# 市区町村サイズくらべ

日本の市区町村（全国1,906件、政令市の区・東京23区は個別カウント）の大きさを、地図上で体感・比較できるツールです。

- **重ね合わせ型**：選んだ市区町村の形を地図上でドラッグして好きな場所に重ね、その場所での見た目の大きさ（メルカトル図法の歪みそのまま）を体感できます。「どこでも北海道マップ」と同じ考え方です。
- **並べて配置型**：市区町村を2〜5個選んで地図に追加し、実際の面積比を保ったまま自由にドラッグして直接見比べられます。

## 使い方（ローカルサーバーの起動）

このツールは市区町村データをJSONファイルとして`fetch`で読み込むため、`index.html`を直接ダブルクリックして開く（`file://`）と、ブラウザのセキュリティ制限によりデータが読み込めません。必ず簡易ローカルサーバー経由で開いてください。

### 方法A: 「起動.bat」をダブルクリックする（一番簡単・Python/Node不要）
フォルダ内の `起動.bat` をダブルクリックするだけで、ローカルサーバーが起動し、既定のブラウザでページが自動的に開きます。使い終わったら、開いた黒いウィンドウ（PowerShell）を閉じるとサーバーが停止します。

同僚のPCで見てもらう場合は、このフォルダ一式（`起動.bat`を含む）をそのまま渡し、`起動.bat`をダブルクリックしてもらうだけでOKです。

### 方法B: 付属のPowerShellスクリプトを手動で実行する
```powershell
powershell -ExecutionPolicy Bypass -File scripts\serve.ps1
```
起動後、ブラウザで `http://localhost:8000/index.html` を開いてください。停止するには実行中のターミナルで Ctrl+C を押します。ポートを変えたい場合は `-Port 8080` のように指定できます。

### 方法C: Python / Node.jsがある場合
```bash
python -m http.server 8000
# または
npx http-server -p 8000
```

### 方法D: VS Codeの「Live Server」拡張機能
`index.html`を右クリック→「Open with Live Server」。

## ディレクトリ構成
```
起動.bat                … ダブルクリックでサーバー起動＋ブラウザを開く
index.html              … エントリポイント
css/style.css           … スタイル
js/
  data.js               … 市区町村インデックス読込・都道府県別データの遅延fetch
  geo.js                … Turf.jsラッパー（平行移動・メルカトル補正・面積計算）
  overlayMode.js        … 重ね合わせ型のロジック
  compareMode.js        … 並べて配置型のロジック
  app.js                … 起動処理・モード切替・検索UI
data/
  muni-index.json       … 検索用軽量インデックス（区・東京23区の個別1,906件＋政令市20件を統合した「市」単位エントリ）
  population.json       … 市区町村コード→総人口（2020年国勢調査）
  municipality/s0010/   … 都道府県別の境界GeoJSON（47ファイル）
scripts/
  build-index.ps1       … data/municipality/s0010から muni-index.json を再生成するスクリプト（政令市の「市」単位エントリも自動生成）
  serve.ps1             … ローカルHTTPサーバー
```

## データの出典
地図データ: © OpenStreetMap contributors

境界データ: 出典 国土交通省 国土数値情報（行政区域データ、N03-21）https://nlftp.mlit.go.jp/ksj/ を加工して作成。データ整形元: [smartnews-smri/japan-topography](https://github.com/smartnews-smri/japan-topography)（簡素化レベル1%、都道府県別GeoJSON）。政令指定都市は区ごとのGeoJSONをTurf.jsで結合し、「市」単位の形状として表示しています。

人口データ: 総務省統計局 令和2年国勢調査「都道府県・市区町村別の主な結果」（e-Stat）より、市区町村（政令市の区・東京23区を含む）ごとの総人口を使用。

## 制限事項
- フリガナ検索は未対応です（元データに読み仮名が含まれていないため）。漢字での部分一致検索、または都道府県→市区町村のプルダウン選択をご利用ください。
- 境界データは簡素化（1%）されているため、詳細な形状の再現性より表示速度を優先しています。
- 人口は2020年（令和2年）国勢調査時点のもので、その後の増減は反映されていません。北方領土の一部および双葉町（当時避難指示区域）は元データが非公表のため人口未表示です。
